# Taza Services

Responsive bilingual (French / Arabic) multi-page local-services website for Taza, Morocco, built only with HTML5, CSS3 and vanilla JavaScript.

## Central data file

Edit **`js/data.js`** for normal content changes.

It contains:
- Business name, phone, WhatsApp, email, address and hours
- French + Arabic business text
- Six services
- French + Arabic service names/descriptions
- Prices, ratings and availability
- Provider names, phone/WhatsApp, photos and experience
- Mini-portfolio images and captions for every service
- Testimonials
- FAQ
- Social links

## Languages

The header includes **FR / العربية**.

The selected language is saved in `localStorage`, and Arabic automatically switches the document to RTL.

## Service portfolios

Every service has a `provider.portfolioImages` array and localized `portfolio` captions.

Example:
```js
provider: {
  portfolioImages: [
    "image-1.jpg",
    "image-2.jpg",
    "image-3.jpg"
  ]
}
```

Replace these image URLs with real work photos later. The service detail page automatically displays the portfolio.

## Icon fix

The previous trust-strip symbols relied on emoji characters. Those can render as empty boxes depending on the browser/OS font.

They have been replaced with inline SVG icons generated by vanilla JavaScript, so they render consistently without an icon library.

## Running

No build process or dependencies are required. Open `index.html` or serve the folder through a simple local static server.

## Contact form

The contact form validates on the frontend and displays a success message. It does not send data to a backend until you connect one.
